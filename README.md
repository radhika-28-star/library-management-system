# Library Management System

## Description

The Library Management System is a Java-based console application developed to manage library books efficiently. This application allows users to add new books, view all books, search for a book, issue books, return books, and delete books.

The project uses Core Java concepts such as Object-Oriented Programming, classes, objects, constructors, methods, ArrayList, Scanner, loops, conditional statements, and switch-case.

## Features

1. Add Book
2. View Books
3. Search Book
4. Issue Book
5. Return Book
6. Delete Book
7. Exit

## Technologies Used

- Java
- Core Java
- OOP
- ArrayList
- Scanner
